Welcome to Smile Classifier

This application uses machine learning to classify images as smiling or not smiling. The model was trained using scikit-learn on Kaggle and deployed as a FastAPI web application.

How It Works

The smile classifier uses a machine learning pipeline:

  • Training: Done in Kaggle using train.ipynb
  • Model: Scikit-learn classifier (Logistic Regression / Random Forest)
  • Preprocessing: Images resized to 64x64, converted to grayscale, flattened, normalized
  • Inference: Local inference.py loads the pre-trained model

Why Scikit-learn?

Scikit-learn was chosen because:

  • Simple and effective for image classification
  • Fast training and inference
  • Well-documented and widely used
  • Easy to deploy and maintain
